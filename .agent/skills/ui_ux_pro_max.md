# UI/UX Pro Max Rules

For professional-tier aesthetic decisions (`@[ui-ux-pro-max]`):

## Typography
- Stick to a maximum of 2-3 font families.
- Establish a clear type scale (e.g., 12px, 14px, 16px, 20px, 24px, 32px, 48px, 64px) and never deviate.
- Improve readability with proper line-height (1.5 for body text, 1.1 - 1.2 for headings) and letter-spacing (tighter for large headings, slightly looser for all-caps).

## Color Strategy
- Utilize the 60-30-10 rule: 60% background/surface colors, 30% secondary/accent background, 10% primary CTA color.
- Ensure text contrast ratios meet WCAG AA standards at a minimum.
- Avoid pure black (`#000000`); use rich dark grays (e.g., `#111111` or `#0f172a`) to reduce eye strain.

## Advanced Layout
- Employ the 8pt grid system. Margin and padding values should be multiples of 8 (or 4 for finer adjustments).
- Group related information visually using proximity and borders/backgrounds (Law of Proximity and Common Region).
