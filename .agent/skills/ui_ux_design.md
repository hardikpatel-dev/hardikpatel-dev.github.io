# UI/UX Design Generation Skill

When tasked with generating novel UI/UX designs or improving existing interfaces:

## Core Principles to Follow:
1. **Fitts' Law:** Make interactive elements large enough and positioned close to where the user's cursor/thumb naturally rests. Primary CTAs must be unmistakable and easily clickable.
2. **Visual Hierarchy:** Use typography (size, weight, contrast) and spacing to guide the user's eye to the most important information first.
3. **Consistency:** Ensure uniform padding, margin, and typography scales across all screens.
4. **Platform Guidelines:** 
   - If designing for Web: Prioritize responsive behavior and accessibility (contrast ratios, aria-labels).
   - If designing for Mobile: Account for touch targets (minimum 44x44px) and thumb reachability.
5. **Aesthetics:** Use modern design trends (e.g., subtle glassmorphism, clean shadows, ample whitespace) to create a premium feel. Avoid generic primary colors; use carefully curated palettes.
