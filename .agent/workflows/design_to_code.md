# Design-to-Code Automation Workflow

When the user asks you to implement a design or convert a mockup to code:

1. **Information Gathering:**
   - If provided an image/screenshot, carefully analyze the layout, typography, colors, spacing, and interactive elements.
   - If a specific framework (e.g., React, Flutter, Next.js) is mentioned, strictly adhere to its architectural best practices.
   
2. **Component Breakdown:**
   - Mentally break down the UI into logical, reusable components before writing any code.
   - Plan proper state management strategies (e.g., props, context, or external state managers) for dynamic elements.

3. **Implementation:**
   - Start by implementing the core layout structure.
   - Use the project's existing design system or Tailwind classes (if applicable) to match the visual fidelity precisely.
   - Pay close attention to responsiveness (mobile-first approach).

4. **Validation:**
   - Cross-check the implemented code against the original mockup.
   - Ensure all edge cases (empty states, hover interactions, loading states) are accounted for.
